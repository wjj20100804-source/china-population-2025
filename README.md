# 中国人口结构全景分层报告（区域细化版）

> 从 14 亿人到 3.4 亿养老金领取者的十一条年龄带与七层身份。
> 数据基准：2025 年末 · 2025 年全国 1% 人口抽样调查 · 2025 年度人社部 / 教育部公报

在线阅读：**https://wjj20100804-source.github.io/china-population-2025/**

## 这份报告在做什么

把 14.05 亿中国人切成足够细的层，并且给每一层标上人数、钱和来源。切法必须同时满足三个条件：

1. 层与层之间不重叠（同一个人不能同时落在两个层里）
2. 每一层都能对上官方统计的一个口径
3. 每一层的钱能说清是从哪来的

轴有两条：**年龄轴**（你是几岁，十一条带子）保证不重不漏，**身份轴**（你靠什么活着，七层主干）保证能说清钱。

## 三类数字必须分开看

| 类别 | 含义 | 标注方式 |
|---|---|---|
| 官方直接公布 | 总人口、年龄组、就业人员、参保与离退休人数等 | 直接引用 |
| 官方总量、作者拆分 | 如职工养老金内部机关事业 / 企业构成 | 「据……推算」 |
| 只能估算 | 养老金金额分档、老年在业行业分布等 | 「作者估算」 |

**引用时请保留这一区分**，否则容易把估算当事实。每层「有多大」基本可信，每层「内部怎么分」是估计。

## 十章结构

1. 数据底座：14.05 亿人的基本盘
2. 主分层：把 14 亿人切成七层
3. 学生层：2.75 亿人在读书
4. 年轻层：1.06 亿人的 18–24 岁
5. 中年层：5.48 亿人的 35–59 岁
6. 老年层：3.21 亿人的十种活法
7. 在业人口：7.25 亿人的职业分层
8. 收入与财富：五等分与基尼系数
9. 六个容易消失的群体
10. 数据说明与引用清单
